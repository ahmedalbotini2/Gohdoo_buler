# `BackindApiAi.kt`

## نظرة عامة (Overview)
يمثل هذا الملف المحلل السحابي للتطبيق (`CloudContentAnalyzer`). تم تصميمه ليكون بمثابة هيكل أو قالب جاهز (Boilerplate Code) يسمح للمطور بربط التطبيق بأي منصة ذكاء اصطناعي سحابية تقدم خدمات فحص الصور والمحتوى الحساس (مثل Google Cloud Vision API أو AWS Rekognition) عبر الإنترنت.

---

## الدوال وشرحها (Methods & Explanations)

### 1. `override suspend fun analyze(bitmap: Bitmap): AnalysisResult`
* **الوظيفة:** الدالة المستقبلية التي ستقوم بأخذ لقطة الشاشة، تحويلها إلى الصيغة المناسبة، إرسالها عبر طلب شبكة (Network Request) إلى الخادم، وانتظار فك التشفير والرد. حالياً تعطي النتيجة الافتراضية `false` لأنها تنتظر ربط المطور لبيانات الـ API الخاص به.
* **لماذا كُتبت هكذا؟** تم إجبار الدالة على العمل تحت سياق `withContext(Dispatchers.IO)`. عمليات الاتصال بالشبكة وإرسال واستقبال البيانات (Network I/O) يمنع أندرويد تشغيلها على المسار الرئيسي تماماً (تجنباً لخطأ `NetworkOnMainThreadException`). الـ `Dispatchers.IO` هو المسار المخصص والمحسن لمثل هذه العمليات.

### 2. `private fun bitmapToBase64(bitmap: Bitmap): String`
* **الوظيفة:** ضغط الصورة وتحويل مصفوفة البايتات الخاصة بها إلى نص مشفر بصيغة `Base64`.
* **لماذا كُتبت هكذا؟** بروتوكولات الإنترنت وواجهات الـ RESTful APIs لا تفضل استقبال ملفات الصور الخام بشكل ثنائي (Binary) داخل نصوص الـ JSON. الطريقة القياسية عالمياً لإرسال الصور عبر الـ API هي تحويلها إلى نص طويل مشفر بـ `Base64` ليتم وضعه بداخل كائن الـ Request بسهولة وأمان. تضمن دالة الضغط بنسبة `85%` تقليص حجم البيانات المرفوعة لتوفير استهلاك الإنترنت وسرعة الاستجابة.
